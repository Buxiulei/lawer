# 录音被否掉的典型：证不到点上 + 对方有利害关系

- **案号**：北京市第三中级人民法院 **（2023）京03民终14444号**
  一审：北京市朝阳区人民法院 **（2022）京0105民初5472号**
- **当事人**：姚某 与 某律所
- **来源**：https://zh.wikisource.org/wiki/姚某与某律所劳动争议二审民事判决书

## 案情要旨

姚某主张与某律所存在劳动关系，提交两项证据：①微信聊天记录中姚某发送的**证人证言**；②与张某的**电话录音**。

## 争议焦点

劳动者单方取得的录音与书面证人证言，能否作为认定劳动关系的依据。

## 结果

上述证据**均不予采纳**。

## 裁判理由（原文）

> "微信聊天记录中姚某发送的证人证言**未经张某签字确认，亦未作为证人出庭**，且**电话录音无法直接证明姚某主张的劳动关系，录音中亦显示张某与某律所存在其他争议具有利害关系**，故对上述证据不予采纳"

> **【本卡引用限制】** A04 原材料另记载"张某与某律所主任存在其他争议"这一身份细节；A04b 核实时未能在判决书摘录段落确认"张某"是否即为该身份，**故本卡不采用该细节**。援引本案时仅使用上述判决书原文已确认的表述。

## 对劳动者的启示

1. **录音失败通常不是因为"偷录违法"，而是因为两件事**：
   - **证不到点上**——录音里没有直接指向待证事实的话（本案要证"存在劳动关系"，录音里却没有对方明确确认这一点）；
   - **说话人有利害关系**——录音对象本身与公司有纠纷，其陈述的客观性被打折。
   录音前先想清楚"我要对方亲口说出哪一句话"（设计问法见 [[sop-luyin-quzheng]]）。
2. **要录到的是确认性表述**，例如："我 X 年 X 月入职、岗位是 X、工资 X 元、由谁给我发工资、谁安排我的工作"——让对方复述并确认，而不是你自己说一堆对方"嗯嗯"。
3. **书面证人证言必须配合证人出庭**。只有一张签字的证言、证人不到庭的，基本不被采纳；自己转发的证言更不行。找证人前先确认对方**愿意出庭**，做法见 [[sop-zhengren-yu-zhengju-qingdan]]。
4. **选证人要避开有利害关系的人**：与公司有未了纠纷的前同事，证明力会被质疑。优先选已离职且与公司无争议、无经济往来的人。
5. **录音只是补强证据**。认定劳动关系的主力仍是工资流水、社保记录、工牌门禁、工作邮件与指令、考勤记录。别把全部希望押在一段录音上。
