# 被裁时没兑现的股票期权，劳动仲裁不管

- **案号**：北京市朝阳区人民法院 **（2023）京0105民初23429号**（2024-03-27）
- **当事人**：张某 与 某公司
- **来源**：https://zh.wikisource.org/wiki/北京市朝阳区人民法院（2023）京0105民初23429号民事判决书

## 案情要旨

张某 2020-04-02 收到聘用通知书及长期激励事务告知书，2020-07-29 签署股票授予协议：兑现起算日 2020-07-01，第二周年兑换 50%、第三周年 25%、第四周年 25%。**2022-04-21 被解除劳动关系后公司拒不兑现**。张某要求公司授予价值 **280,000 元**的限制性股票单元或支付等额货币。

诉前，朝阳区劳动人事争议仲裁委员会作出 **京朝劳人仲不字（2023）第 3458 号不予受理**通知书；公司抗辩本案不属于劳动争议受理范围。

## 争议焦点

股权激励（RSU / 限制性股票单元）争议是否属于劳动争议的受理范围。

## 结果

**不属于人民法院审理劳动争议案件的受理范围**（仲裁亦不予受理）。

## 裁判理由

据判决书转述：仲裁委已出具不予受理通知书；法院认定该项请求"不属于人民法院审理劳动争议案件的受理范围"。

## 对劳动者的启示

1. **被裁员时未兑现的股票/期权/RSU，在朝阳区大概率走不通劳动仲裁这条路**。别把它写进仲裁请求（会被裁定不予受理，白白耗掉时间），应准备走**普通民事合同之诉**（依据授予协议的约定、管辖条款与准据法）。
2. **最有效的做法是在离职谈判阶段一并解决**：把股权部分与经济补偿写进同一份解除协议，明确"已授予未归属部分如何处理""加速归属或折算现金 X 元于 X 日前支付"。协议一签就变成合同债权，比事后单独打官司容易得多（见 [[template-xieshang-jiechu-shencha-qingdan]]）。
3. **协议里的"一揽子结清"条款会把股权一并盖掉**。如果股权问题谈不拢，就**不能签**含"双方再无任何争议"的条款，或必须加一句"本协议不涉及乙方持有的股权激励权益，双方另行处理"。
4. **先把文件收齐**：聘用通知书、长期激励告知书、股票授予协议、归属时间表、历次归属通知与账户截图（境外平台的账户页面在离职后可能被关闭，**离职前先全部导出**）。
