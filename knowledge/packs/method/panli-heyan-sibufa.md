# 判例核验四步法

> **产品化输入**：本卡沉淀自用户案实战——鲁学骏案若只凭案号+摘要就当先例写进书状，会被对方当庭反用。
> agent 引用任何判例（作先例、类比、佐证）进入**对外文书或向用户的确定结论**前，**必须逐步过完这四步**。
> 达不到的判例：标"仅内部参考，不得写入对外文书"。

## 第一步：读全文，不靠案号+摘要

- 案号、标题、一句话摘要**不足以支撑引用**——判决的真实裁判逻辑只在全文的"本院认为"段。
- 只有案号就敢当先例，是危险的（同一案号的实际结论可能与你的假设相反）。
- 拿不到全文 → 该判例只能标"内部参考"，不进书状。

## 第二步：区分"当事人自认的事实前提" vs "法院独立认定的裁判结论"

- 判决里的某句话，要分清是**当事人主张/自认**（对第三案毫无先例价值）还是**法院查证后的裁判认定**（可引）。
- 识别信号：法院认定常见"本院认为""本院采信……的主张（基于……证据）""经查明"；当事人陈述常见
  "原告主张""被告答辩称""上诉人认为"。
- 典型陷阱（鲁学骏案）："两公司混同用工"是**被告答辩状自认**、非法院认定——法院据此得出的还是
  否定第二公司责任的反向结论。当自认被误当裁判结论引用，先例价值为零甚至反向。
- 正例（张恺/杨振伟案）："本院采信……工龄从X年计算的主张"是**法院基于企业登记信息的独立认定**——可引。

## 第三步：否定性核验（不只看有什么，还看没有什么）

- 除了看判决**支持了什么**，还要看它**没说什么**：你想主张的那个词/那个法律概念，全文出现过吗？
- 例：想引某案支持"连带责任"，先全文搜"连带"二字——**零出现**说明法院根本没走到连带这一步，
  不能作连带先例（鲁学骏案"连带二字零出现"即此）。
- 同理：想引某案支持某赔偿项，看法院是否实际判了该项、还是绕过/驳回了。

## 第四步：给出【可用 / 不可用 / 反向】结论字段

- 每条核验过的判例**必须带一个明确结论字段**，供下一个人直接判断，不用重读：
  - **可用**：法院独立认定、支持你的主张方向、相关表述在全文中确实存在。
  - **不可用**：全文未支撑、或只是当事人陈述、或该论点被程序性绕过（悬空未裁）。
  - **反向**：判决实际结论与你的主张相反——引用会被对方反用（最危险，必须标红）。
- 附一句依据（哪段判词、可用于哪个场景[庭前预判/连带/赔偿计算/调解定价]）。

## 一句话

**读全文 → 分清自认还是裁判 → 搜它没说的 → 标可用/不可用/反向。** 四步缺一，判例不进书状。
