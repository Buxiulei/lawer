# 《异议函》通用模板

## 适用场景

公司单方作出**调岗、降薪、待岗/放假、取消绩效或奖金、变更工作地点**等决定（书面或口头），
劳动者**既不想认可、也不想被扣旷工**时，当天或次日发出。

本模板是所有单方变更类场景的通用件；调岗明显不合理、准备正面对抗时改用
[[template-jujue-tiaogang-huifuhan]]（更强硬，直接要求撤回通知）。

**为什么必须发、必须在几天内发：**
京高法发〔2024〕534 号《解答（一）》第 61 条——劳动者已按变更后的安排**实际履行**，
再以未采用书面形式主张变更无效的，按《劳动争议司法解释（一）》第 43 条处理
（原文见 [[statute-jgf-2024-534-jieda-1]]）。实务含义：按新安排干了且超过一个月不书面异议，
事实变更可能被认定成立。本函第三部分的"两条腿走路"表述就是专门对冲这一条。

## 全文模板

```
                          异 议 函

致：【公司全称】人力资源部 并 法定代表人【　　】

本人【姓名】，【部门】【岗位】。就贵公司于【　年　月　日】作出的
【《岗位调整通知》/《薪酬调整通知》/《待岗通知》/口头通知】，本人
提出如下异议：

一、本人不同意上述调整/安排

【原岗位/原薪资/原工作地点】系双方劳动合同第【　】条明确约定的内容。
根据《中华人民共和国劳动合同法》第二十九条“用人单位与劳动者应当
按照劳动合同的约定，全面履行各自的义务”、第三十五条“用人单位与
劳动者协商一致，可以变更劳动合同约定的内容。变更劳动合同，应当采用
书面形式”，贵公司未与本人协商一致即单方变更，本人明确不予认可。

二、请贵公司在【三】个工作日内书面说明以下事项

1. 本次调整的具体依据（规章制度名称、条款编号，并提供该制度经
   《劳动合同法》第四条规定的民主程序制定及向本人公示/告知的证据）；
2. 本次调整的经营必要性与目的正当性（生产经营情况发生何种变化）；
3. 调整后本人的岗位名称、岗位职责、工作地点、汇报关系；
4. 调整后本人的工资构成与数额，以及与原待遇相比是否存在不利变更；
5. 【如涉及工作地点变更】贵公司拟采取的弥补措施（交通补助、班车、
   住宿安排等）。

三、本人的履行立场

在双方就上述事项协商一致之前，本人将继续按照【原岗位/原工作地点/
原工作内容】正常提供劳动。**如贵公司坚持要求本人到新岗位/新地点
报到，本人将在保留本函全部异议及法律权利的前提下服从出勤安排；
该等出勤系为避免被认定为旷工而采取的必要措施，不构成本人对劳动合同
变更的同意，亦不视为本人对上述调整的追认。**

本人保留依据《中华人民共和国劳动合同法》第三十八条及《劳动合同法
实施条例》第十八条主张权利的全部权利。

                          异议人（签名并按手印）：__________
                                          日期：【　年　月　日】
```

## 填空位说明

| 填空位 | 怎么填 |
|---|---|
| 公司全称 | 与营业执照一致，取自 gsxt.gov.cn 查询页 |
| 法定代表人 | 同上；抬头同时写"人力资源部 并 法定代表人"，避免 HR 单线截留 |
| 通知作出日期与文件名 | 照抄公司文件的标题与落款日；**口头通知就写"口头通知"并写明时间、地点、谈话人姓名职务** |
| 原岗位/原薪资/原工作地点 + 合同第【　】条 | 翻劳动合同原件，把条款号写准；合同里写"全国""北京"这类宽泛表述的，改按 [[template-jujue-tiaogang-huifuhan]] 第 3 点主张"约定不明＋实际履行地视为确定" |
| 第二部分第 5 项 | 不涉及工作地点变更时整条删掉 |
| 第三部分【原岗位/原工作地点/原工作内容】 | 按本次被改的那一项填，其余删；**加粗那段一字不改** |
| 【三】个工作日 | 一般填 3 个工作日；公司文件自己设了回复期限的，填不长于该期限 |

## 送达方式（三通道，缺一不可）

| 通道 | 操作要点 |
|---|---|
| ① 企业邮箱 → HR + 直属上级 + 法定代表人，**抄送本人个人邮箱** | 保留"已发送"截图与含邮件头的原文；离职前把邮件转发到个人邮箱 |
| ② 企业微信 / 钉钉 / 飞书**文字**消息（不发语音） | 发送后截图＋录屏，原手机保留 |
| ③ **EMS 特快专递** 寄营业执照登记住所 + 实际办公地 | 详情单"内件品名"栏逐字写 `关于岗位调整的异议函（1 份）`（按实际文件名改） |

EMS 操作要点：寄件前拍文件全文、文件与详情单同框、封装过程、已封口信封正面四组照片；
保留详情单存根原件；妥投后打印全部物流轨迹；对方拒收同样有效，保存原封未拆信封当庭拆封；
合同有送达地址条款的优先按该地址寄并在函中注明。

## 注意事项

- **第三部分的"两条腿走路"表述是本模板的核心，务必原样保留。** 它同时解决两个风险：
  拒不到岗 → 被按旷工违纪解除；照做不吭声 → 被认定实际履行、事实变更成立（《解答（一）》第 61 条）。
- 发函归发函，**出勤照旧**：正常到岗、正常打卡、正常干活。异议归异议，出勤归出勤。
- 公司让在原通知上签字的，**只签**："仅证明收到，内容不认可，异议函另行提交"；不要签"已阅""同意"。
- 本函**不是**解除通知，发出后劳动关系继续。降薪差额实际发生后，再评估是否升级为被迫解除
  （见 [[statute-lhtf-38-beipo-jiechu]]）。
- 公司在三个工作日内不回复的，把"已催告、未答复"本身作为后续主张"未协商一致"的证据留存；
  可按同一模板再发一次并注明"系第二次催告"。
- 完整的当天动作顺序与证据固定清单见 [[sop-tiaogang-yingdui]]。
