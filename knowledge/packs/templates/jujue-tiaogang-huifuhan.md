# 《拒绝调岗回复函》模板

## 适用场景

收到公司《岗位调整通知》，且调岗**明显不合法或不合理**、劳动者决定正面对抗、要求撤回通知时使用。
典型情形：合同明确约定岗位却被单方调走；调岗紧随"拒签自愿离职申请""告知怀孕"之后；
新岗位专业完全不匹配且无培训；工资明显下降或通勤时间大幅增加且无交通补助。

**与 [[template-yiyihan-tongyong]] 的选用区别：**

| | 异议函（通用） | 拒绝调岗回复函（本卡） |
|---|---|---|
| 立场 | 保留异议 + 服从出勤，不拒绝到新岗 | 明确不同意，要求撤回，继续在**原地点原岗位**出勤 |
| 适用 | 事实不清、还想观望、公司理由未知 | 事实清楚、证据在手、调岗不合理明显 |
| 旷工风险 | 低（已声明服从出勤） | **较高**——必须坚持每天到原工作地点正常打卡留痕 |

**北京口径依据（原文见 [[statute-jgf-2024-534-jieda-1]]）：**

- 《解答（一）》第 59 条：合同**明确约定岗位但未约定如何调岗**的，不符合《劳动合同法》第 40 条
  所列情形时，单位自行调岗属**违约行为**，参照原岗位工资标准补发差额；合同**未约定或约定不明**的，
  合理性审查看四要素——经营必要性、目的正当性、调整后岗位劳动者能胜任、工资待遇等劳动条件无不利变更。
- 《解答（一）》第 60 条：工作地点宽泛约定为"全国""北京"的属**约定不明**，已在实际履行地工作的
  视为双方确定具体工作地点；即便约定可单方变更，仍须合理性审查，并考量单位是否提供交通补助、班车等
  弥补措施。

## 全文模板

```
                    关于《岗位调整通知》的回复

致：【公司全称】

本人于【　年　月　日】收到贵公司《岗位调整通知》，现回复如下：

一、本次调岗不具备合法性与合理性

1.（合同依据）双方劳动合同第【　】条明确约定本人岗位为【　　】、
   工作地点为【　　】，且未约定贵公司可单方调整岗位/工作地点。
   依《北京市高级人民法院、北京市劳动人事争议仲裁委员会关于审理
   劳动争议案件解答（一）》第 59 条，在不符合《劳动合同法》第四十条
   所列情形时，用人单位自行调整劳动者工作岗位的属于违约行为。

2.（合理性四要素）本次调岗不符合“用人单位经营必要性、目的正当性，
   调整后的岗位为劳动者所能胜任、工资待遇等劳动条件无不利变更”的
   要求，理由：
   （1）经营必要性：【贵公司未说明生产经营发生何种变化；本人所在
        部门仍在正常运转/贵公司仍在对外招聘同岗位人员，附招聘信息
        截图】；
   （2）目的正当性：【本次调岗发生在本人 XX 之后（如：本人拒绝签署
        自愿离职申请之后 / 本人告知怀孕当日），具有明显的针对性】；
   （3）胜任性：【新岗位为 XX 专业岗位，与本人 X 年的 XX 从业经历
        及专业背景不匹配，贵公司亦未提供任何培训安排】；
   （4）劳动条件不利变更：【新岗位月工资由 X 元降至 X 元，降幅 X%；
        工作地点由北京市朝阳区 XX 变更为 XX，单程通勤时间由 X 分钟
        增加至 X 分钟（附导航截图），贵公司未提供任何交通补助或
        班车】。

3.（工作地点）双方劳动合同虽约定工作地点为“全国”“北京”，但依
   上述《解答（一）》第 60 条，该约定属于对工作地点约定不明；本人
   自入职以来实际工作地点一直为【　　】，应视为双方已确定具体工作
   地点。贵公司不得仅以该宽泛约定为由，无正当理由变更本人工作地点。

二、本人的处理意见

1. 本人**不同意**本次岗位/工作地点调整，请求贵公司撤回该通知；
2. 本人将于【　年　月　日】起继续在【原工作地点】按【原岗位】
   正常出勤并提供劳动；
3. 如贵公司认为本人不能胜任工作，请依《劳动合同法》第四十条第二项
   规定的程序，先行提供培训或调整工作岗位，并出具书面考核依据；
4. 如贵公司以本人未到新岗位报到为由记录旷工或作出处分，本人不予
   认可，并保留主张违法解除劳动合同赔偿金的权利。

                          回复人（签名并按手印）：__________
                                          日期：【　年　月　日】
```

## 填空位说明

| 填空位 | 怎么填 |
|---|---|
| 收到通知日期 | 照抄通知落款日或实际收到日（邮件时间戳为准） |
| 第 1 点合同第【　】条 + 岗位 + 工作地点 | 翻劳动合同原件逐字抄；**合同没明确约定岗位的，整个第 1 点删掉**，只打第 2 点合理性四要素 |
| （1）经营必要性 | 附证据：部门仍在运转的组织架构图/OA 截图；公司仍在招同岗位的招聘网站截图（带日期） |
| （2）目的正当性 | 写清"调岗紧接在哪件事之后"，时间点越近越有力（拒签离职申请、告知怀孕、提出欠薪主张等） |
| （3）胜任性 | 写明本人专业背景与年限、新岗位所需技能、公司未安排培训 |
| （4）不利变更 | 工资降幅算百分比；通勤用地图导航截图标注单程时间；写明有无交通补助/班车（**无**对劳动者有利） |
| 第 3 点 | **仅在合同工作地点写"全国""北京"等宽泛表述时保留**；合同写了具体地址的整点删掉 |
| 第二部分第 2 项日期 | 填收到通知后的下一个工作日，表明不间断出勤 |

不适用的分点整段删除，不要留空的【】交给公司看。

## 送达方式（三通道，缺一不可）

| 通道 | 操作要点 |
|---|---|
| ① 企业邮箱 → HR + 直属上级 + 法定代表人，**抄送本人个人邮箱** | 保留"已发送"截图与含邮件头原文 |
| ② 企业微信 / 钉钉 / 飞书**文字**消息 | 发送后截图＋录屏，原手机保留 |
| ③ **EMS** 寄营业执照登记住所 + 实际办公地 | 详情单"内件品名"栏逐字写 `关于《岗位调整通知》的回复（1 份）` |

EMS 要点同其他函件：寄前拍全文、文件与详情单同框、封装过程、封口信封正面；留存详情单存根原件；
妥投后打印全部轨迹；拒收也有效，保存原封未拆信封当庭拆封。

## 注意事项

- **发本函的同时必须继续在原工作地点正常打卡出勤**，并每天留痕（打卡记录、工位照片、
  向上级发送的工作汇报邮件）。本函最大的风险就是被公司按旷工处理——《解答（一）》第 80 条允许
  规章制度没写时依《劳动法》第 3 条第 2 款按严重违反劳动纪律解除。
- 拿不准调岗是否"明显不合理"、或证据还不齐时，**先发通用异议函**（保留异议 + 服从出勤），
  等公司书面回复后再决定是否升级为本函。两条腿走路风险最低。
- 不要拒绝**正常的**工作安排（临时项目、合理出差、报销路费且保留原薪的短期异地培训）——
  北京有拒绝异地临时培训被认定合法解除的案例（见 [[sop-tiaogang-yingdui]]）。
- 公司强推并实际降薪的，差额发生后书面催告；仍不补的再评估第 38 条被迫解除
  （见 [[statute-lhtf-38-beipo-jiechu]]）。
- 公司以"拒绝调岗 = 旷工"解除的，属违法解除，可主张 2N 或继续履行。
