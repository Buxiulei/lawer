# 危机事件处置与事后追责应对 SOP

> **这张卡有两段**：上半段是**事发当时**的处置骨架（并行轨「危机事件处置」），
> 下半段是**事后**家属追责时的应对。两段共用同一份记录——
> **当时怎么记，决定了事后能不能站住。**

## 一、事发当时：评估 → 联系 → 记录 → 随访

### 适用场景判定

来访在会谈、消息或电话中出现：自伤/自杀意念、计划或未遂、自残、伤害他人的意念或行为、
未成年人遭受性侵或虐待的线索、家暴、失联、疑似精神障碍急性发作。

### 第 1 步：评估并当场写下判断依据

- 评估内容：意念/计划/手段/时间的具体程度、既往史、当前支持系统、物质使用、可及的危险物品；
- **当场写下评估依据与时间点**（言语原话摘录、行为观察、既往记录关联）。
  事后回忆重写的评估，在追责场景中说服力大打折扣。

### 第 2 步：联系（顺序不能乱）

1. **紧急联系人 / 监护人**——精神卫生法第 28 条第二款把"立即采取措施予以制止并送医"的
   义务给了**近亲属、所在单位、当地公安机关**（见 [[statute-jswsf-28-30-31-weiji-songyi]]）。
   我方的作用是**触发这些主体**，不是自行送医。
2. **联系不上或情况紧急** → **110**（人身安全危险）／**120**（已发生伤害行为、需医疗处置）。
3. **非紧急的心理援助资源** → 告知对方可拨打 **12356**（号码卡见 [[data-counseling-weiji-rexian]]）。
4. **建议就医**：怀疑可能患有精神障碍的，**应当建议其到符合精神卫生法规定的医疗机构就诊**
   （第 23 条第三款），并书面留痕（[[template-zhuanjie-han]]）。

> 通知监护人时**说什么、不说什么**：说明"依据知情同意书中的保密例外条款"、当前风险与建议动作；
> **不复述咨询内容细节**（守则 3.3 最低限度原则）。逐句话术见 [[script-weiji-tonghua-huashu]]。

### 第 3 步：记录（免责的关键证据）

按 [[template-weiji-chuzhi-jilu]] 记满六项：**时间 / 判断依据 / 风险等级 / 联系对象与方式 /
对方响应 / 后续处置决定**。**处置动作不进记录，事后与"什么都没做"在举证上等价。**

### 第 4 步：随访

- 约定随访时点并执行，记录随访结果；
- 是否恢复咨询关系**需重新评估**，不自动恢复；不适合继续的，走终止与转介
  （[[template-tingzhi-fuwu-tongzhi]]、[[template-zhuanjie-han]]）。

### 边界（三条不能越）

1. ⛔ **不作诊断、不作治疗**（精神卫生法第 23 条第二款）——记录里不写诊断性结论；
2. ⛔ **不自行强制送医、不限制人身自由**——无法定权限；
3. ⛔ **不因"怕麻烦"而不预警**——守则 3.2(1)(2) 的预警责任独立于法定送医主体的划分。

**涉未成年人遭受性侵或虐待的报告义务问题，见 [[risk-qiangzhi-baogao-zhuti]]
（未经律师书面确认不得作为结论输出）。**

## 二、事后：家属追责的应对

### 场景

来访在咨询期间或之后自伤、自杀或伤害他人，家属指控咨询师"明知风险却未尽提醒/转介义务"。

### 分步动作

1. **第一时间封存全部记录**（咨询记录、危机处置记录、消息往来、转介留痕），
   **禁止任何补记、修改**；需要补充说明的另起一份并注明撰写时间与目的。
2. **按四步复盘自查**：评估做了吗？联系了吗（联系谁、几点、对方怎么答）？
   建议就医了吗（有无留痕）？随访了吗？——**四项齐备是最强的免责组合**。
3. **不主动对外表态**，一切沟通改为书面；涉及媒体或网络扩散的，同步走
   [[sop-mingyu-qinquan-yingdui]] 固定证据。
4. **对家属的书面回应**：表达关切 + 说明已履行的动作（不含咨询内容细节）+
   告知可通过何种渠道进一步沟通；**不承认过错，也不指责逝者或家属**。
5. **时效**：人身损害类主张适用普通民事诉讼时效 3 年
   （见 [[statute-mfd-188-susong-shixiao]]、[[data-counseling-shixiao-qixian]]）。

> ⚠️ **本次调研未查到可公开引用的同类裁判文书**（【待核实】），
> 因此**不得**向用户给出"这类案件通常判……"的倾向性结论。

## 证据固定清单

- [ ] 危机处置记录（六项齐备）
- [ ] 与紧急联系人/监护人的通话与消息记录（含时间戳）
- [ ] 报警/急救的呼叫记录（如有）
- [ ] 建议就医与转介的书面留痕
- [ ] 随访记录
- [ ] 知情同意书中的保密例外条款签署件

## 常见错误

- ❌ 只在咨询记录里写一句"来访情绪低落"，不写评估依据与处置动作。
- ❌ 只用微信口头提醒家属，事后拿不出留痕。
- ❌ 事发后补写记录"完善细节"。
- ❌ 出于同情越界代办（陪同就医、垫付、代为决策）——好意会变成"实际接管"的证据。
- ❌ 因保密顾虑而完全不联系任何人——守则 3.2 的例外正是为此设的。
