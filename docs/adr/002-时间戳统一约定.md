# ADR-002 时间戳统一约定
日期：2026-08-19 · 状态：已接受
背景：DDL 默认值 datetime('now') 产出「YYYY-MM-DD HH:MM:SS」(UTC 空格格式)，而 JS 的 toISOString() 产出「…T…Z」。两种串混存后裸字符串比较排序错乱（'T'>' '），曾构成 OTP 冷却绕过路径（auth 已在查询侧归一并加回归测试钉住）。
决策：**全项目 canonical 时间格式 = SQLite datetime('now') 的 UTC 空格格式，秒精度**。
- DDL 默认值保持 datetime('now') 不改（与问爻/NBDpsy 移植代码习惯一致，已并入 main 的 29 表零改动）。
- 应用层需要写时间列时，一律经 lib/db 导出的 `nowSql()` / `toSql(date)` 助手（WS1 随 ws/billing 交付），禁止直接落 toISOString() 串。
- 时间比较：同为 canonical 串可直接字符串比较；任何来源不明的串先 datetime() 归一。
- 行内排序优先用 id（AUTOINCREMENT）而非时间串。
后果：秒级精度（毫秒场景用 id 或专列）；边界（API 入参 ISO8601）在路由层转换。
