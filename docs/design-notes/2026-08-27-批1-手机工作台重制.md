# 批 1 · 手机端工作台重制（规格）

> 上游：DESIGN.md「视觉方向 v3」三决定（2026-08-27 用户拍板）。本篇是批 1 的执行规格，改的是**结构**不是文案、不是字号体系（字号归批 3）。
> 证据来源：前端页面盘点（断点/对比度实测）、govuk-mapping 调研（数值来自 govuk-frontend 6.4.0 编译 CSS 直接 grep + vercel/chatbot 源文件，非转述）。

## 目标（三条，缺一不验收）

1. **393px 下，"现在做什么"一眼跳出**——不靠底色，靠结构。
2. **五种卡片去掉颜色仍能分清**（灰度测试，见验收）。
3. **393–1279 不再是同一套版式**——至少 `md`(768) 起有独立处理。

## 现状（数字，不是印象）

- `Workbench.tsx` 全部响应式类只有四处，全是 `xl:`。`sm/md/lg` 一处没用。
- 五种语义共用 `rounded-[12px] border border-line`，只靠底色区分；底色间对比度 **1.02–1.15:1**。
- 393px 演示夹具 3736px 高 / 8 张视觉相同的卡；真实案件更长，**3736 是地板**。

## 层级方案：两个色相 + 灰，六级分量

品牌三色不动（勃艮第红 `#8B2942` / 淡金 `#F5E6C8`·深金 `#8A7340` / 米白 `#FFFCF5`）。**底色组 `surface / surface-2 / primary-wash` 可动**（用户拍板①）。
GOV.UK 组件只借**结构语言**，颜色一律换成我们的：GOV.UK 蓝 → 勃艮第红；GOV.UK 绿 → 深金；GOV.UK 灰 `#cecece` → `--line`。

| 分量 | 元素 | 借用 GOV.UK | 结构（手机） | 色 |
|---|---|---|---|---|
| **6 最重** | 危机轮首段（热线） | Panel · interruption | **整块填色、反白文字**；三个号码各是占满一行的 `tel:` 按钮（≥44px 高） | 底 `--primary`，字/按钮 `--gold-wash` |
| **5** | 行动卡「现在做什么」 | Notification Banner 外框 + Task List 行 | **4–5px 实边框包整卡** + **填色顶栏**（"现在做什么 · 1/3"）；顶栏下每条待办一行：勾选框 / 标题 / 右侧截止日 tag / 「为什么」展开 | 边框与顶栏 `--primary`，顶栏字 `--on-primary`，卡身 `--surface` |
| **4** | 期限提示 | Notification Banner（两段式） | **顶栏填色 + 白底内容**，无外框（与行动卡的"外框"区分开） | 顶栏 `--gold` / 字 `--ink`；**不用红**（红只给风险条款与不可逆操作） |
| **3** | 草稿卡 | Summary Card | 1px 外框 + **灰底标题栏**，标题栏右侧放「编辑」「导出」 | 外框 `--line`，标题栏 `--surface-2`（可调深到 ≥1.3:1） |
| **2** | 法条卡「依据」 | Details | **默认折叠**，summary 一行"《劳动合同法》第四十七条 · 看逐字原文"，**左侧 8px 灰边**；展开后原文缩进 | 左边 `--line`，summary 字 `--primary-ink` |
| **1** | 记录块（证据/时间线回显） | Summary List | **无外框**，键值对行，行间 1px 底线，键加粗 | 底线 `--line` |
| **0 裸** | 正文块 | 无（chatbot 式） | **零装饰**，文字直接流在页面底上；左侧 28px 小头像可选 | — |
| （已有） | 用户消息 | chatbot 用户气泡 | 保留现状：靠右、圆角气泡、`max-w-[min(80%,56ch)]` | 现有 |

**为什么行动卡不用"气泡"而用"外框+顶栏"**：调研建议给行动卡气泡、其余不给；但用户消息已经是气泡（靠右）。两个气泡会稀释。**气泡 = "有人说了这句"，外框+顶栏 = "去做这件事"**——语义不同，形状也该不同。

**同一色相内的两级**：热线 = 整块填色（最重）；行动卡 = 边框+顶栏（次重）。**不撞色**是因为分量差一档，不是色相差。

## 断点

| 宽 | 档案面板（现在 `aside`） | 消息列 |
|---|---|---|
| `< md` (393–767) | **底部抽屉**（已定，08-27）。不做第五个 tab：tab 是路由跳转会卸载 `Workbench` 组件、**正在生成的 SSE 回答当场没了**，而看档案的时刻正是流最可能在跑的时刻；底部导航已有「证据」「文书」两个 tab 与档案内容重叠；抽屉机制（`casePanel.tsx` Provider + `AppSheet`）已在仓库里 | 单列，`px-4` |
| `md`–`lg` (768–1279) | **可折叠侧抽屉**（默认收起，顶部一个按钮） | 单列，`max-w-2xl mx-auto` |
| `xl+` (1280) | 现状固定右栏 | 现状 |

消息列上限借 vercel/chatbot：`max-w-4xl`(896px)，输入框容器同宽、**`sticky bottom-0`** 不是 `fixed`，背景同页面底、无顶部分割线。
消息间距：`gap-5`(20px) 手机 / `md:gap-7`(28px)。

## 不做（批 1 边界）

- **不改字号体系**（批 3）。现有正文字号不动。
- **不改文案**、不改 charter、不改任何 `lib/agent/` 下的东西。
- **不动 `xl` 现有桌面布局**，除非断点重排必须碰。
- **不改名**（批 2）。
- 不引新依赖。

## 验收（全部要证据，不收"做完了"）

1. **393px 全页截图**，与改前对照。改前基线：`/home/roots/caiyuan-ws/eval-evidence-archive/frontend/before-20260827/workbench-mobile.png`（393×3736，manager 08-27 上午截，线上 476ed69）。
2. **灰度测试**：同一张 393 截图转灰度（`convert -colorspace Gray`），**五种卡片仍能分清**。这是"结构区分不靠颜色"的直接证明。
3. **"现在做什么"在 393px 下**：行动卡是首屏内**唯一**带填色顶栏+实边框的元素（热线块只在危机轮出现）。
4. **768px 与 393px 版式确实不同**——两条**只有真做了断点才会成立**的检查（原写法"侧抽屉按钮可见"作废：那个按钮是 `xl:hidden`，393/768、改前/改后都可见，**检查在什么都不做时也会通过**）：
   - **消息列左边界 x 坐标**：393 是 `px-4` 满宽，768 起 `max-w-2xl mx-auto` 居中——同一段文字在两张截图里的左边界必须不同，**给数**。
   - **抽屉出现的边**：`<md` 从下方升起，`md`–`lg` 从侧边推入。两张截图各一张抽屉打开态。
5. **性能工装**（批 0 收进 `scripts/perf/` 的那套）在 393 跑一遍，**含灵敏度对照臂**；掉帧那列照旧写「无法真实模拟」，不补数。
6. **Lighthouse a11y 桌面 + 移动分别审**（移动版式那半棵树在 412 下不渲染，只审移动会得假满分）。热线 `tel:` 按钮 touch target ≥44px。
7. tsc 干净 + 全量 vitest 绿。
8. **一个 PR**，base=main（批 0 合入之后）。

## 风险

- 危机轮首段现在是确定性首段（`CRISIS_OPENER_HEAD/TAIL` 常量）拼进正文的，**改它的渲染不许动它的文本**——评测判据 `危机轮N-首段无杠杆` 读的是文本。渲染层做，文本层不碰。
- Details 折叠法条卡：评测 G4（法条引用四态）判的是**归档正文**，不是 DOM 展开状态——折叠不影响判据。但**「看逐字原文」链接必须仍在 DOM 里**（不能 lazy 到点了才有）。
