# 第五道确定性闸：伪逐字引号引用（产品队列 · 预写）

**性质**：行为面改动，验证需真跑 S14 3/3 —— 大概率排暂停后。
本文件先备**离线可测的那一半**（纯函数 + 单测），开窗即贴；真验等窗。

案例（S14 #3，评测官核实为**真 L1 行为挂**）：本轮**未检索到 534 卡**，
模型却用引号"逐字引用"534§55**(4)**——实为**记忆改写冒充逐字**，且子项错
（库内真身是 §55(1)，措辞不同）。

> 用户拿这种"逐字引用"上庭，对方一查即穿。**这正是 charter §3 要防的核心伤害**：
> 不是说错话，是**给了一件看起来可以直接用、实际一碰就碎的东西**。

## 二、判据：什么算"被当作法条原文的引号内容"

**不能见引号就查**——引号在正当输出里到处都是（引用户原话、给可照读话术、标"哪些话绝不能说"）。
只查**被呈现为法条/文号原文**的那些：

```ts
/**
 * 引号内被**当作法条原文**呈现的片段。
 *
 * 【为什么必须限定呈现方式】引号在我们的输出里是高频且**正当**的结构：
 * 引用户自己说过的话、给可照读话术、标注"这句绝不能说"。见引号就查会把它们全卷进来，
 * 而那三类恰恰是 charter §6 明确要求的东西——**误剥会把产品最有用的部分剥掉**。
 *
 * 所以要两个条件同时成立：①引号内含法条特征（第X条／〔20XX〕X号／款项标记）；
 * 或 ②引号紧跟"原文/规定/写的是/载明"这类**宣称逐字**的引导语。
 */
const VERBATIM_LEAD = /(原文|规定|写的是|载明|明确|条文)[：:是]?\s*$/;
const STATUTE_SHAPE = /第[一二三四五六七八九十百零〇0-9]+条|[〔[【]\s*\d{4}\s*[〕\]】]\s*\d+\s*号|第[一二三四五六七八九十]+款|[（(]\s*[一二三四五六七八九十0-9]+\s*[）)]/;

export function quotedStatuteSpans(text: string): { quote: string; at: number }[] {
  const out: { quote: string; at: number }[] = [];
  for (const m of text.matchAll(/[「『"“]([^」』"”\n]{8,200})[」』"”]/g)) {
    const inner = m[1];
    const before = text.slice(Math.max(0, (m.index ?? 0) - 12), m.index ?? 0);
    if (STATUTE_SHAPE.test(inner) || VERBATIM_LEAD.test(before)) {
      out.push({ quote: inner, at: m.index ?? 0 });
    }
  }
  return out;
}
```

## 三、核对：与**本轮注入块**逐字比对（归一后）

```ts
/**
 * 引号内容是否有本轮注入的支撑。
 *
 * 归一化只抹排版差异（空白、全半角括号、书名号），**不抹字**——
 * 「记忆改写冒充逐字」正是改了字，抹字就把要抓的东西抹没了。
 *
 * 【为什么必须是"本轮注入"而不是"整个知识库"】S14 那轮根本没检索到 534 卡。
 * 拿全库比对会让"这轮没查却背出来"通过——而**背出来的那次恰恰是最危险的**：
 * 它没有经过检索，也就没有经过任何新鲜度与版本校验。
 */
const normQuote = (s: string) => s.replace(/[\s　]/g, '').replace(/[（）()〔〕[\]【】《》]/g, '');

export function unsupportedVerbatimQuotes(text: string, injected: KnowledgePack[]): string[] {
  const corpus = normQuote(injected.map((p) => `${p.title}\n${p.body}\n${JSON.stringify(p.facts ?? {})}`).join('\n'));
  return quotedStatuteSpans(text)
    .filter(({ quote }) => !corpus.includes(normQuote(quote)))
    .map(({ quote }) => quote);
}
```

## 四、处置：改口，不静默删

与案号闸同型（占位符替换），但**措辞不同**——案号可以换成【案号待核实】，
法条原文换成占位符会读不通，所以**整句改口**：

```
原文：《解答（一）》第 55 条规定："<伪逐字内容>"
改后：《解答（一）》第 55 条**这一条我需要核实原文再引给你**——我不凭记忆复述条文。
```

**为什么宁可改口也不留**：留着的伪逐字**看起来完全可用**，用户会照抄进申请书、当庭念出来。
剥掉只是少一句依据，留着是给他一件**一碰就碎的证据**。
（与污染断言那条相反的取向——那条是**判据**误伤正确输出，这条是**产品**输出伪造内容，
方向不同：判据宁可漏判，产品宁可少说。）

## 六、单测（离线，开窗即可跑）

```ts
describe('第五闸：伪逐字引号引用', () => {
  const pack = (body: string) => ({ id: 'p', title: 't', body, facts: {} } as never);

  it('引号内容在本轮注入里逐字存在 → 放行', () => {
    const injected = [pack('用人单位违反本法规定解除或者终止劳动合同的，应当依照本法第四十七条规定的经济补偿标准的二倍向劳动者支付赔偿金。')];
    const t = '《劳动合同法》第八十七条规定："用人单位违反本法规定解除或者终止劳动合同的，应当依照本法第四十七条规定的经济补偿标准的二倍向劳动者支付赔偿金。"';
    expect(unsupportedVerbatimQuotes(t, injected)).toEqual([]);
  });

  it('**本轮没注入却引号逐字 → 抓住**（S14 实测形态：记忆改写冒充逐字）', () => {
    const injected = [pack('与 534 无关的另一张卡')];
    const t = '《解答（一）》第 55 条第(4)项规定："用人单位主张……的，应当承担举证责任。"';
    expect(unsupportedVerbatimQuotes(t, injected)).toHaveLength(1);
  });

  it('排版差异不算改写：空白与括号全半角归一后仍算支撑', () => {
    const injected = [pack('期间以时、日、月、年计算。')];
    const t = '《民事诉讼法》第八十五条：" 期间以时、日、月、年计算。 "';
    expect(unsupportedVerbatimQuotes(t, injected)).toEqual([]);
  });

  // 【防误剥三条：这三类引号是 charter §6 明确要求的东西】
  it.each([
    ['你刚才说"我是不是真的很没用"，这句我听见了', '引用户原话'],
    ['明天照读这句："这份我先带回去看看，明天上午给您答复。"', '可照读话术'],
    ['这几句绝不能说："我不干了"、"随便你们"', '标注禁语'],
  ])('正当引号不被误抓：%s（%s）', (t) => {
    expect(unsupportedVerbatimQuotes(t, [pack('无关内容')])).toEqual([]);
  });
});
```
