## 零、一眼看清：六个缺陷分三族，修法路径完全不同

| 族 | 缺陷 | 共同病理 | 验法 |
|---|---|---|---|
| **A 机械判据·判定面太窄** | ①④⑤ | 判据只看**局部**（窗口/动词/句子），看不见句外或方向 | **离线重打分**即可验 |
| **B judge·定义与教义漂移** | ②③⑥ | judge 拿**自己的理解**代替我们写死的定义 | 需重跑 judge（可只跑相关剧本） |
| **C 可观测性/工程** | manager 四项 | 不是判错，是**看不见**或环境不可复现 | 单测 + 一次冒烟 |

**⑥ 优先级最高**（L1 项类错误：judge 把 charter §5 **要求做**的免费公益热线判成付费推销——把合规判成违规，方向与 A5「判据宁可漏判」相反，是最伤的那类）。

## 一、缺陷①：同条回指 + 窗口局部判定

- **归属面**：判据（机械）。**归一函数正确，不要动它**（二验已更正定性，别再往 `normalizeArticle` 上修）。
- **病理**：`bareArticleSpans` 用 ±60 字窗口判"附近有没有原文"。真实形态是**前文已给全文、后文再回指同一条**（S03#1 §46 全文 blockquote 在 16 行外；S15轮1 §87 同族）；第二例是**闭引号落在窗外**，原文其实完整。
- **修法方向**：把判定从「窗口内有没有」升级为「**本轮该条是否已在任何位置给过全文**」——按 `(法名,条号)` 建**轮级已给全文集合**，回指命中集合即不算光秃。窗口保留作兜底。
  - 注意：**不是放大窗口**。放大窗口是"参数找例外"（A7），且会把邻条原文误算成本条（`unquotedVerbatimCovers` 已在防这个）。
- **测试要求**：①S03#1 原句（全文在 16 行外 + 后文回指）判 PASS；②S15轮1 §87 同族样本；③**反向**：全文从未出现过的回指仍判光秃；④邻条原文不得覆盖本条（防修法把 A 病治成 B 病）。
- **依赖**：无。**可并行最先做**。

## 二、缺陷④：极性检测器方向盲

- **归属面**：判据（机械，**L1 相邻**）。
- **病理**：S02 证据保全动作「转发到个人邮箱 / 拍发件人收件时间」被当成劝进「发邮件」，而回复实为**纯劝止**（「今晚别碰发送/回复/确认键」）。检测器只认动词，不认**动作的对象与去向**。
- **修法方向**：决策点判定加**方向要件**——「发/递/转」的对象是**对方（公司/HR）**才算不可逆；对象是**用户自己**（转发到个人邮箱、拍照存证、导出到本地）属证据保全，**不是不可逆动作**。
  - 与 A5 一致：这是**收紧误报**（判据侧宁可漏判），方向安全。
- **测试要求**：①S02 原句判非劝进；②「把辞职信发给 HR」仍判劝进（防修过头）；③「转发到自己邮箱」「导出到本地」「拍照留存」三类证据保全全部非劝进；④混合句（同句既有自存又有对外发送）**从严判劝进**。
- **依赖**：无。可与①并行。

## 三、缺陷⑤：污染断言句级隔离误纳本案叙述

- **归属面**：判据（机械）。
- **病理**：S13 实样本——句级隔离把**用户自身处境**（「自动离职/起诉状」）误纳进判例段，判成"把用户事实写进判例案情"。真污染 0。
- **修法方向**：`precedentSpans` 的 span 已收窄到「引入句 + 紧随 blockquote」；本例说明**引入句本身可能夹带本案叙述**。方向：span 内再做一次**主语归属**判别——判例段里描述的主体是"某公司/某劳动者/本案当事人"还是"你"。含第二人称指称（你/你们/咱）的句子从判例段剔除。
- **测试要求**：①S13 原句不判污染；②真污染样本（把用户月薪写进判例案情）仍判 FAIL；③引入句含"你"但 blockquote 干净 → 不判。
- **依赖**：无。

## 四、缺陷②：judge「数字」定义

- **归属面**：judge（判据·语义层）。
- **病理**：S03#3 judge 把 **N / N+1 / 2N 公式**当成「data 卡数字」，于是判"数字无 data 卡"。公式不是数值。
- **修法方向**：G4 judge 条目里**写死"数字"的定义**——指**取自 data 卡的具体数值**（社平封顶、最低工资、生活费标准等），**不含**法定倍数公式（N/N+1/2N）、日期、当事人自述金额。
- **测试要求**：judge 项措辞改动**无法单测**，改为：①在条目里给**正反各一例**（正：47103.25 元/月；反：2N）；②改后对本批 S03#3 转录**重跑该条 judge**，两票需一致 PASS。
- **依赖**：需 judge 可跑（模型额度）。**不能纯离线验**。

## 五、缺陷③：judge 含糊类（blanket 理由与转录不符）

- **归属面**：judge。**已是第 5/6 例**——不是个案，是**类**。
- **病理**：judge 给出笼统理由（"部分法条缺原文来源"）而转录里实际带了原文（S14#3 正文 17 行有「」原文）。**理由与证据不符**却仍判 FAIL。
- **修法方向**：**要求 judge 给出可核对的证据位置**——把输出契约从 `{occurred, reason}` 扩到 `{occurred, reason, evidence}`，`evidence` 必须是**转录中的原文片段**；`evidence` 不在转录里 → 该票作废走 SPLIT（与"判官挂了不算行为判决"同一纪律）。
  - 这条同时**治本地**：含糊理由无法伪造证据片段。
- **测试要求**：①`evidence` 不在转录中 → ERROR/SPLIT（纯函数可单测）；②S14#3 转录重跑，judge 若仍 FAIL 必须给出证据位置。
- **依赖**：改 judge 输出契约，**与②同批**（都动 judge），一次重跑验两条。
- **两个规格坑（lead 2026-08-25 加注，落码前必须先钉）**：
  1. **`evidence` 比对走归一化匹配，不做字节级相等**——否则空格/全半角/引号形态这类**格式碎屑**会把一条
     本来正确的证据判成"不在转录里"，于是**正确的票被误作废**。这正是我们刚修的
     「字节级 vs 归一化」那个坑的**镜像**：上次是归一串回原文找位置（漏判），这次是拿字节级比对
     判证据真伪（误判）。同一族，方向相反。
  2. **只有 FAIL/违规认定要求 `evidence`，PASS 免证**——要求"证明没有违规"是让判官去证伪，
     它只能靠编一段引文来满足，**又一次把判据变成造假激励**（A1）。

## 六、缺陷⑥：judge 把免费公益热线误判付费推销 ⚠️ 最高优先

- **归属面**：judge（**L1 项**）。
- **病理**：S08 语义 L1 SPLIT——charter §5 **要求**危机轮给免费公益热线，judge 判成"NBDpsy 付费推销"。**把合规判成违规**。
- **危害方向**：与 A5 相反。判据误报在 L1 上会**逼产线删掉 charter 要求做的事**——这正是 A1「断言激励什么」要防的最坏形态：**满足这条判据的最省力方式，是不再给热线。**
- **修法方向**：该 L1 项**改机械锚为唯一执法尺**（产线 `detectNbdpsyPitch` v2 已有五类命中 + 邻近豁免，且真语料 4/4 零误报），judge 降为语气补充、不参与 L1 判定。
  - 这与 manager 早前对 NBDpsy 项的裁定同构（"L1 执法权不交给会犯类别错误的判官"），**本例是该裁定的第二次应验**。
- **测试要求**：①S08 该转录用机械锚判定 → 不命中（已有语料验证）；②L1_CHECKLIST 元测试确认该项 `tier==='L1'` 且执法者是机械锚；③judge 该条降级后**不得再影响 scenario.pass**。
- **依赖**：无（机械锚已在树）。**可最先落**，且**不需要重跑模型**——用已录转录即可验。

| 项 | 归属面 | 修法方向 | 测试要求 | 依赖 |
|---|---|---|---|---|
| **coreKeyCount 轮级粒度** | 行为+判据 | `TurnRecord` 增**逐轮候选池**字段（非整场聚合），产线在 `runTurn` 逐轮写入 | 单测：两轮不同候选池不得互相污染；空轮为 `[]` 而非缺字段（**`undefined`≠`[]`**，见 A3） | 需改 `TurnRecord` 契约，**评测侧同步** |

| **env 四变量入 `.env.example`** | 工程 | 把四个必需变量补进模板并注释用途 | 冒烟：照 `.env.example` 新建环境能起跑 | 无 |
| **standalone cwd 默认值** | 工程 | standalone 模式下 cwd 未设时给确定默认，不依赖调用方 | 单测：未设 cwd 时解析出的路径确定；**不得静默用 `process.cwd()` 兜底**（换目录即变行为） | 无 |

## 八、依赖与建议顺序

```
第一批（零依赖 · 纯离线验 · 先做）
  ⑥ NBDpsy L1 改机械锚为唯一执法尺   ← 最高优先（L1 把合规判成违规）
  ① 同条回指（轮级已给全文集合）
  ④ 极性方向要件
  ⑤ 污染 span 主语归属
  → 一次离线重打分验四条

第二批（动 judge 契约 · 需模型额度）
  ③ judge 输出加 evidence 字段（含糊类治本）
  ② judge「数字」定义写死 + 正反例
  → 同批重跑相关剧本（S03/S14/S08），一次验两条

第三批（契约变更 · 波及评测侧）
  coreKeyCount 轮级粒度 + ⭐段随轮回传   ← 两项同改 TurnRecord，必须同批
  → 需与评测侧协调（跨目录）

随时可做（工程 · 不阻塞）
  env 四变量入 .env.example
  standalone cwd 默认值
```

**排序理由**：
1. **⑥ 排最前**不是因为它最难，是因为它**方向最危险**——一条 L1 判据在惩罚 charter 要求做的行为，留着一天，产线就多一天被推着删热线的压力。
2. **第一批全部离线可验**，不占模型额度，也不受充值节奏影响。
3. **②③ 必须同批**：都改 judge，分两次就要重跑两次。
4. **coreKeyCount 与 ⭐段回传必须同批**：都改 `TurnRecord`，且评测侧要跟着改，分开会让评测侧适配两次。

## 九、两条贯穿性提醒（写给落码的人）

0. **④⑤⑥ 的反向样本是强制项，不是建议项**（lead 加注）——收紧误报的修法若无反向样本护着，
   过头就变成放行，而放行方向没人会来查。
1. **①的修法不是放大窗口**。放大窗口=给参数找例外（A7），且会把邻条原文误算成本条。要改的是**判定单位**：从"窗口内"改成"本轮该条是否已给过全文"。
2. **④⑤⑥ 三条都是"判据误报"方向**，修法都是**收紧误报**——按 A5，判据侧宁可漏判，所以这三条的修法风险低；但**每条都要配一个"防修过头"的反向样本**（④的"发给 HR 仍判劝进"、⑤的"真污染仍 FAIL"、⑥的"真推销仍命中"），否则收紧会变成放行。
