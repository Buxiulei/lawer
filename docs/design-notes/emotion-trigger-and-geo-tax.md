# 方案一：情绪场景走触发，不走词面匹配

## 为什么这条路是对的（不是绕过，是治源）

`crisis.ts` 文件头当初就写对了：**"危机表述与资源卡用词天然没有词面交集，靠调权重治不好"**。
实测印证：S08 轮1「今天又被拒了。我是不是真的很没用，35岁不到就已经废了」——
库里**有** `emotion-caiyuan-xinli-jieduan`（被裁后心理阶段·陪伴话术·冲动拦截），
但用户说"被拒/没用/废了"，卡的 keyword 是"被裁情绪/心理阶段/灾难化思维"，**字符层面零交集**。

**这不是召回没调好，是词面通道对这类表达根本不存在。** 情绪表达的特征是
**说的是自己的感受，不是事情的名称**——而卡是按事情的名称索引的。

## 触发条件（全部现成，零新增信号）

| 信号 | 来源 | 性质 |
|---|---|---|
| `assessCrisis(message).triggered` | `crisis.ts` | 确定性纯函数 |
| 持续痛苦证据 `store.distressEvidence(db, caseId)` | 已在 `orchestrator.ts:189` 为 NBDpsy 闸计算 | 结构化事实 |

**不新增模型判断**——与⭐核心条"由结构化事实判定，不让模型自己勾"同一条纪律。

## 注入规则

```
危机轮（crisis.triggered）：
  位 1：危机资源卡（确定性 unshift，**不动，L1**）
  位 2–3：情绪支持卡 **上限 2 张**（合计⭐位≤3，manager 已批上限 3）
  其余位：走阈值 1.0——**恒 <1 分的尘埃直接不填，宁可空着**

子危机轮（distressEvidence 达标但未触发危机）：
  情绪支持卡 上限 2 张，其余同上
```

**为什么上限 2–3 而不是填满 5**（ws2-agent 的自我否定，manager 已批）：
`applies_to='情绪支持'` 全库仅 13 张、情绪指南型仅 3 张——**5 个位子会把库里几乎所有
情绪卡一次倒进上下文，反过来稀释危机指令**。**多给不等于更好，在危机场景尤其如此。**

## 选卡顺序（确定性，不靠打分）

1. `applies_to` 含"情绪支持"且 `type='情绪指南'` 的卡优先（3 张，最贴陪伴场景）；
2. 不足则取 `applies_to='情绪支持'` 的话术卡；
3. 仍不足则**留空**，不用其它类型凑数。

## 验收

- 危机轮：位 1 仍是危机资源卡（L1 回归，不得被挤）；
- S08 那 92 轮：情绪支持卡进包 ≥1 张（当前 0）；
- **反向样本（防修过头）**：非情绪轮不得被塞情绪卡（否则每轮都在"接住情绪"，
  法律干货被挤掉——这正是 D14「法律问答过程中不插推销」的同类风险）；
- 行为面改动 → 全转录回放 + S03/S14 重跑。

# 方案二：地名税修法

## 定性（manager 已入册）

> **"北京"是地域过滤条件，不是主题相关性信号；产品全域北京，这个词的信息量是零。**
> 信息论意义上，**一个在全体样本中恒真的特征，判别力为零**。

实测：157 轮里含地名词的 18 轮，**18/18 全部**被 `data-beijing-shiye-baoxianjin` 与
`data-beijing-zuidi-gongzi` 占位，恒定 **2 个位子 / 六分之二的注入预算**；
「今天北京天气怎么样」两卡各 3.250 并列第一。

**阈值治不了它**：keyword「北京」命中得 +3，远在阈值 1.0 之上。

## 三个候选修法

| 方案 | 做法 | 评估 |
|---|---|---|
| **A（推荐）** | 地名类 keyword **不参与打分**，改作**过滤维度**（有地域标注的卡，地域不符则排除；地域相符不加分） | 语义正确：地域是**筛选条件**不是**相关性**；改动集中在打分函数一处 |
| B | 地名 keyword 大幅降权（+3 → +0.2） | 治标；降到多少是拍脑袋，且**"当前只有北京"是今天的数据事实不是结构保证**（同 MIN_KEYWORD_LEN 那条教训） |
| C | 数据面：把两张卡的 keyword「北京」删掉 | **不可取**——那两张卡确实是北京的数据卡，删掉会让**真正问北京最低工资的人**找不到它 |

**推荐 A**，理由是它把"地域"放回它该在的位置：**产品全域北京 ⇒ 全部卡地域相符 ⇒
地域维度对排序零贡献**，这正是它应有的效果，而不是靠一个手调的小权重去逼近零。

## 需要 manager 定的一点

**地名词表从哪来？** 建议**不硬编码**——从知识卡的 `region` 字段取（已有字段），
凡出现在任何卡 `region` 里的词即视为地域词。理由：硬编码词表会漂
（今天 12 个区，明天加"通州区"或跨省扩展就漏），**而 region 字段是这件事的唯一事实源**。

## 验收

- 「今天北京天气怎么样」不再命中那两张数据卡（当前各 3.250 并列第一）；
- **真正问北京最低工资的 query 仍能命中它们**（防修过头，这是合入门槛）；
- 18 轮地名占位归零，让位后接手的是切题卡（实测让位后是 `method-panli-heyan-sibufa` 等）；
- 带上下文检索**在此之后**再上——否则收益 +19 会被这条税吃成 +1。
