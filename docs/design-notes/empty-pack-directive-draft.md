## 一、指令正文（拟注入 system prompt，仅在空包轮出现）

```
【本轮无可引用依据】
这一轮没有检索到任何可引用的知识卡。你手上**没有**法条原文、判例、社平工资/最低工资等数字。

因此这一轮：
- **不要**给出法条条号、判例案号、任何具体数字或期限天数——你手上没有它们的出处，
  凭印象写出来的每一个数字，用户都会拿去谈判或写进申请书。
- **可以并且应该**做这些事：
  1. 把用户这一轮说的事实接住、复述确认（尤其时间点、金额、谁说了什么）；
  2. 问清楚下一步判断必需的事实（一次问 1–3 个最关键的，不要问卷式轰炸）；
  3. 给**不依赖具体条文**的流程性指引（该保存什么证据、该去哪个窗口、下一步该做什么动作）；
  4. 需要依据才能答的问题，**明说**："这一问要引法条/数字，我先去核实依据再回答你，
     现在先把 X 和 Y 确认清楚。"
- 这一轮的目标不是给答案，是**把事实问清楚**——依据下一轮补上。

【例外：用户这一问的核心就是期限】
如果用户问的正是"我还能不能申请仲裁""还有几天""过期了没"这类**期限本身**的问题，
**不许用相对时间糊弄过去**，必须两件事一起给：
1. 明说：**"这个期限我必须核实准确了再答——答错的代价你承担不起。"**
2. 给保守指引：**"在我核实之前，请按最紧的可能期限准备，不要拖。"**
   （随后给出在最紧假设下当天就能做的动作。）
理由：**超期是不可逆的，而提前准备的代价只是白忙。** 期限不确定时，
唯一对用户安全的建议是按最紧的假设行动。
```

## 二、设计说明（给审稿人）

**1. 为什么"不得引用"必须配"可以做什么"**
只禁不给替代时，模型面对"用户提问 + 不许引用"只剩两条路：编造（L1）或沉默（无用）。
上面第 2 段的四条给出第三条路——**把这一轮变成问诊轮**，这本来就是 charter §4 的
合法动作，不是新发明。

**2. 为什么点名"用户会拿去谈判或写进申请书"**
这是**给禁令一个理由**，而非光下命令。charter §2 的原则是"关键动作附一句为什么"，
对模型自己的约束同样适用——只有理由成立，它在边界情形才知道往哪边靠。

**3. 与第五闸的关系：同一条防线的事前版**
第五闸是**事后剥**（引号内引用对不上本轮注入 → 剥掉改口"我不凭记忆复述条文"）；
本指令是**事前禁**（根本没有注入 → 先说清别引）。两者不重复：
- 有料轮：闸负责"引的必须是给过的"；
- 空包轮：本指令负责"什么都别引"，闸作为兜底仍然生效。
**闸不撤**（manager：防线不撤，真正的修法是给料）。

**4. 一个必须避免的副作用：别让它变成万能免责句**
风险：模型可能学会在**非空包轮**也说"我需要先核实依据"——那会退化成
"什么都不答"。防线两条：
- 指令**只在空包轮注入**（条件触发，不常驻）；
- **判据侧配对**：非空包轮出现"我需要先核实依据"却**手上确实有该条卡**时，
  应判缺陷（该给的没给）——与 D14 频控/正向断言的成对原则同源。

**5. 措辞里刻意不用的词**
- 不用"抱歉/很遗憾"——charter §6 禁口癖与套话，且道歉不解决问题；
- 不用"我不知道"——**用户请不起律师，把它当唯一依靠**；说"不知道"与说
  "这一问要引依据，我先核实"在信息量上相同，但后者给了时间线和下一步。
  （manager 提级召回的理由正在此：**若 71% 轮次都触发这条，产品就变成"大部分时候说我不知道"**
  ——措辞能缓解观感，但**根治靠召回**，措辞不是替代品。）

## 三、两个待定项 → manager 已裁（2026-08-25）

**裁定①（行动卡截止时间）**：**允许相对时间**（"今天下班前""48 小时内"），
**禁止法定期限**（"15 日内提起诉讼"）。**manager 补一种情况**（已写进上方指令正文）：
若用户这一问的**核心就是期限本身**，不许用相对时间糊弄——必须同时给
"这个期限我必须核实准确了再答"+"在我核实之前按**最紧的可能期限**准备"。
> **超期是不可逆的，而提前准备的代价只是白忙。**
> 期限不确定时，唯一对用户安全的建议是按最紧的假设行动。

**配套判据（本条必须配）**：空包轮 ∧ 用户问期限 → 断言"明说要核实"与"保守指引"
**两者同时在场**；缺任一为缺陷。（只给(a)=把问题丢回给用户；只给(b)=没说清这是保守
假设不是结论。）

**裁定②（EMPTY_PACK 留痕）**：批准，且 **manager 升一级——它不只是排障留痕，是运营指标**：
> **空包率就是召回质量的直接度量。**

- **口径**：按场景分层（危机/首诊/常规）、按日聚合；
- **警戒线初值**：**单日空包率 > 40% 报 manager**（上线后按真实分布校准）；
- **理由**：上线后若空包率维持在当前 71% 的量级，**产品实际上大部分时候在说
  "我要先核实"**——那是必须触发召回攻坚的信号，**不能靠人偶尔想起来去查**。
- 另一半理由（原稿）：没有留痕就无法从归档判断"这一轮是没料还是有料没用"，
  而这两者修法完全不同。这次能定案保底渲染是否开火纯属侥幸——靠第五闸恰好留了痕。
