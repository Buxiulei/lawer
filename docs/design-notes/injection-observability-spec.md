# 注入产物可观测接口 · 规格（WS2 出稿，manager 已批合并，落码前最后一稿）

> **为什么合并成一件做**（manager 批）：四个字段回答的是同一个问题——
> **"这一轮，系统到底给了模型什么？"** 一次接线、一套三态语义、一次回放验证。
> **它是两条线的前置依赖**：S19 深会话剧本（无它则⭐四态无法判定，剧本白跑）、
> 空手感知（无它则触发与否不可复核）。
> 基础设计沿用已批的 `turnrecord-contract-change.md`（三态非布尔 / 候选池与渲染分离）。

## 一、四个字段

| 字段 | 语义 | 回答什么 |
|---|---|---|
| `coreCandidateKeys?: string[]` | ⭐候选池（S1∪S3∪S2∪S4 算完的结果） | **系统算出哪些是核心条** |
| `coreBlockRendered?: string[]` | ⭐段**实际渲染进 prompt** 的条 | **模型真的收到了吗**（"传了≠渲染了"） |
| `renderAdded?: string[]` | 保底渲染补进正文的条 | **渲染开没开火**（§27 那次靠闸留痕侥幸定案，不该有第二次） |
| `substantiveHitCount?: number` | 本轮注入包中有实质命中的卡数 | **手上这几张能不能用**（空手感知的判据本体） |

## 二、三态语义（四个字段一致，A3「不知道≠零」）

| 值 | 含义 | 判据处置 |
|---|---|---|
| **字段缺失**（`undefined`） | 这份产物**不知道**（旧产物/跑在旧代码上） | **跳过该判据**，产 `na: mechanism_unavailable`，不计过不计挂 |
| **`[]` / `0`** | 机制跑了，**产出确实为空** | **真信号**——⭐空、渲染没开火、无实质命中 |
| 非空 | 正常 | 正常判 |

**合并成 falsy 判断就把"旧产物"和"机制真空了"判成同一件事**，而后者恰恰是最该报警的。
**历史产物全都没有这四个字段**——回放兼容走"缺失=跳过"这一支，**不得因此判 PASS**。

## 三、写入点（收敛点，不在分叉点）

统一在 `orchestrator.ts` 内部产出（与账本接线同一条纪律：**记录这件事只该有一处代码负责**）：
- `coreCandidateKeys` / `coreBlockRendered`：`prompt.ts` 组装⭐段时回报给 orchestrator；
- `renderAdded`：保底渲染函数已返回 `added`，直接透出；
- `substantiveHitCount`：检索后、注入前算一次（**与阈值 1.0 同源，用同一个判定函数**，
  不得在评测侧重算——A31 两把尺不共用刻度的反面：**这里必须共用同一把尺**）。

经既有 `record`/`meta` 帧发出 → 落 `TurnRecord`。**不改 `runTurn` 签名。**

## 四、消费方

| 侧 | 用它做什么 |
|---|---|
| 产线 | 空手感知触发判定（`substantiveHitCount === 0`）；`KNOWLEDGE_MISS` 通知**挂同一判据** |
| 判据 | ⭐四态；上下文检索相关性；空手感知是否该触发而未触发 |
| 运营 | **空包率指标**（A34：按场景分层、按日聚合、单日 >40% 报警）；实质命中位占比 |

**⚠️ 指标定义锁定**（A34 第四重）：`substantiveHitCount` 的判定规则、阈值 1.0、
`MIN_KEYWORD_LEN`、子串规则**构成指标语义**，改动须 manager 同级审批并说明对历史数据的影响，
**不得作为"调优"顺手改**。建议这四项常量**集中一处并就地注释**——规矩要写在它保护的东西旁边。

## 五、验收（三条硬条件）

1. **三态各有单测，且断言三者处置不同**（防"三态写了但两态同路"）；
2. **旧产物零改动可回放**（拿 `results/` 里任一历史 JSON 验，全部走"缺失=跳过"）；
3. **候选池非空但⭐段未渲染的样本能被区分出来**——**这正是 S03 那次没被发现的形态**
   （当时候选池空、⭐段没出现，而报告写成"给了"）。**新字段若区分不出它，这次改动就白做。**

**行为面纪律**：本改动落在 `app/src`，基线 175cad3 的行为面动了 → **全转录回放 + S03/S14 重跑**。
回放若零分歧，commit 说明写明"经 N 条真实转录回放实证无行为差异"——**让后人知道这个结论是验出来的不是想出来的**。

## 六、一句写进注释的话

> **这四个字段不改变系统做什么，只让我们知道系统做了什么。**
> 在此之前，"⭐有没有出现""渲染有没有开火"**只能靠侥幸判定**——
> §27 那次能定案，纯粹是因为第五闸恰好留了痕。**同样的运气不该指望第二次。**
