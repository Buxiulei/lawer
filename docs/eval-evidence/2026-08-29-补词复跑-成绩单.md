```

```
**实测反事实**：若键放宽到概念本身，
```
「裁决→申请执行」 ⇒ ho-zhixing-2 捞到 sop-zhixing-sop  **是**
「判→申请执行」   ⇒ hb-2        捞到 sop-zhixing-sop  **是**
```
> **理由写在概念层，键落在词面层——留出集抓住的正是这个落差。**
> 「裁决**书**」「裁决**下来**」是两个具体四字串，不是「裁决」这个概念。
