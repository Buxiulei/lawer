# 预设措辞类断言全量普查（评测官 → manager 裁 → ws2 一次性整改）

基准：ws/backend@b75be9a scripts/eval/scenarios.ts（52 条机械断言）+ assertions.ts 谓词。
判定问题：「这条真的能用字面匹配吗？」三类处置：**(a)** 改结构式/语义匹配；**(b)** 改 judge 项+可判定标准；**(c)** 可字面匹配，保留但词表含变体。
通用规则（对所有正则）：①窗口一律双向；②否定前缀/引号内引用排除（无空话事故）；③正样本单测用真实转录原话。

## 原则：三种断言形态，风险方向不同
- **正向·概念在场**（「提到录音/笔录/举证责任」）：词是领域术语，字面可行 → (c)。
- **正向·话术复现**（「三不」「拖延话术」「正常化紧张」）：模型表达方式无穷，字面匹配= 预设它怎么说 → 误 FAIL 高发，(a) 或 (b)。**本批 4 起误报全在这一类**（S09 决定权、S15 明确拒绝、S08 无空话[负向但语境]、S01 三不）。
- **负向·禁语 absent()**：失败方向是漏判（false PASS）不是误 FAIL；保留但词表加变体+语境排除 → (c)。
- **精确值**（号码/条号/数字）：必须字面，(c)。
