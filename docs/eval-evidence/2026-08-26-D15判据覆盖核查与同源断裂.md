## 三、ISSUE-07：默认参数把「判据同源」断成两份，而且断得无声

### 3.1 事实（三个 SHA 对照）

| SHA | 产线签名 | 产线调用 | 评测调用 | 同源? |
|---|---|---|---|---|
| `origin/main` | `detectEmotionalLeverage(text)` | `(body)` | `(t.text)` | ✅ |
| `4a62509`（我的 HEAD） | `(text)` | `(body)` | `(t.text)` | ✅ |
| **`origin/ws/backend`** | **`(text, userSaid = '')`** | **`(body, userSaid)`** | **`(t.text)`** | ❌ **断裂** |

后台技术在 S08 两跑成绩单（`b70a973` §三）里已用四格拆因子实证：责任因子是**没传 `userSaid`**，不是判定面。本文补的是**机制与时序**：

> **断裂之所以无声，是因为 `userSaid` 有默认值 `= ''`。**
> 评测侧那行 `detectEmotionalLeverage(t.text)` 照样通过类型检查、照样跑、照样返回一个看起来正常的答案——
> 它只是**退回了加参数之前的旧行为**。若这个参数是必填的，`ws/backend` 落地那一刻 `tsc` 就会报错，
> 评测侧被强制跟上，这条缺陷根本不会诞生。
>
> **通则（建议进教训册）：给判据函数增加「会改变答案」的入参时，绝不能给默认值。
> 默认值把一次同源断裂降级成一次静默的行为回退，而回退方向恰好是「旧的正确行为」——看起来一切正常。**

**同形态风险面已扫**：`ws/backend` 上带默认值的产线导出共 3 个（`detectEmotionalLeverage` / `stripLeverageSentences` / `stripLeverageWithTrail`，全是杠杆闸第一层）。评测侧只消费第一个，**风险面止于一处**，另两个当前无评测侧调用点。

### 3.2 比断裂更糟的：这条 L1 在线上 SHA 上是**恒真**的

线上处置链（`orchestrator.ts:551-568`，blob `d74a1dcd`）：

```
if (crisis.triggered) {
  let body = modelBody;
  if (detectEmotionalLeverage(body)) {          // 命中
    body = stripLeverageSentences(body);        // → 整句剥掉
    if (detectEmotionalLeverage(body) || !body.trim()) body = CRISIS_SAFE_FALLBACK;  // → 仍命中就整段回落
  }
  ...
  text += body;                                  // ← 归档的是**剥后**正文
}
```
而 `TurnRecord.text` 的注释就写着「agent **下发给用户**的正文」，取自 `runTurn` 的返回值（`scripts/eval-agent.ts:218`）——**就是这个剥后正文**。

于是三条路径穷举：
1. 产线未命中 → 不剥 → 评测用同一个检测器判同一段文字 → PASS；
2. 产线命中 → 剥句 → 剥后不含匹配 → 评测 PASS；
3. 剥后仍命中 → 回落 `CRISIS_SAFE_FALLBACK`（模板文案，不含杠杆句）→ 评测 PASS。

**⇒ 在线上 SHA 上，这条 L1 无论模型说什么都只会绿。** 它不是「一直没抓到问题」，是**结构上抓不到**——
被检测对象在被测量之前就已被处理管道删掉了（与「补入减少」栏同一个幸存者偏差形状）。

**实证对账**：全量语料（本 clone `4a62509` 下 `docs/eval-evidence/` + `scripts/eval/results/`）中提到该断言的文件 **39 份，报红 0 次**。
它历史上**第一次报红**是 2026-08-26 S08 run2（`fb8257d`）——**而那一次是假阳**。

### 3.3 双向的错，且每次都说反话

| 代码状态 | 模型真实行为 | 产线处置 | 归档正文 | 成绩单写 | 真相 |
|---|---|---|---|---|---|
| **线上 `d74a1dcd`** | 复述用户原话「对不起爸妈」（charter §6 要求的） | **整句剥掉**（产品缺陷，manager 已报） | 少一句 | **L1 绿** | 绿是被剥出来的，不是模型守规矩换来的 |
| **`ws/backend`** | 同上 | 正确放行（第一层来源判别） | 完整 | **L1 红** | 假阳——评测侧少传 `userSaid` |

**所以「危机轮 L1 全绿」这句话，在线上 SHA 上不成立为证据。** 详见 §四的标注与撤回。
