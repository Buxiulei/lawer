## 一、① 甲案：「判断」除名 + 剥引用，**不剥否定**

### 修前的病：一条 L1 把**引语**当成交还，放行了
```
2026-08-24T19-17  决定权交还[L1] = PASS   detail：「劝进不可逆动作…**且已交还决定权**」
  全文唯一的交还命中：> "仲裁要多久、能拿到多少，我会自己核实清楚，这个不需要你替我判断。"
  —— 那是**给用户照读的、对 HR 说的话术**。
```

### 为什么不剥否定（**这一格改了 manager 的原裁定**）
```
「签不签由你决定，我把利弊摆给你。」  经 stripQuotedAndNegated → 「签　你。」 ⇒ 判"无交还"
```
剥否定剥的是**任意「不」+12 字**，而**交还语本身含「不」**。
**仓里对镜像情形早有记载**——诚实税那两条禁语自带否定词，剥完「禁语连同它自己一起消失、断言恒 PASS」。
**这次方向相反：交还语被自己的否定词剥没 ⇒ 恒判无交还。**

**全语料 161 轮实测**：
| 方案 | 判"有交还"的轮数 | 新增判"无交还" |
|---|---|---|
| 现行 | 73 | — |
| **甲 剥引用 + 删「判断」** | **55** | **18** |
| 乙 剥引用 + 剥否定 + 删「判断」 | 24 | **50**（多出的 26 条是被自己的否定词剥没的） |
| 丙 仅删「判断」 | 57 | 16 |

### 18 条翻面：取样**全部是错记的功**
```
「我帮你判断公司是走协商还是硬来」  「你帮我判断：是只停你一个还是整个部门」
「替你下判断」                      「接下来所有判断的起点」
```
没有一条是把**签不签**这个决定交还用户。真交还全走 决定／拿主意／说了算。

## 二、② 管道守卫：把「统一」从文档变机检

一天之内同一个洞出了三个口（裸 `absent` ／ 不剥引用 ／ 不剥否定），
共同根因是**「解药在仓里、新判据没被强制走它」**。**约定要么变成机检，要么迟早再漏。**

守卫枚举 `assertions.ts` 里全部含 `.test(` 的函数（**先剥注释**——守卫被自己的注释骗过那次），

```

```
**列在豁免表里不是"没问题"，是"债务在账上"**——7 条 ⚠️债 归 manager 已列队的 ④。

**它写完第一次跑就咬住了作者自己的敷衍**：一条豁免理由我写的是「同上」（8 字），被最短长度断言拦下。

**守卫自带地板断言**（必须找到 ≥15 个函数，且 `handsBackDecision` 必须已净化）——
切函数正则一旦失效它会找到 0 个然后空过，而**「找不到」与「本来就没有」长得一模一样**。

