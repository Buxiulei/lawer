| 问题侧 | 答案侧 | 判读 | 处置 |

## 四、本次基线**不能**证明的（先写死）

1. **不能证明"改了就会好"**——基线只描述现状。提升幅度要等对比批。
2. **不能把"实质命中率"当作产品质量指标**：它量的是**检索是否给了 agent 料**，
   不量 agent 拿到料之后用得对不对。**两件事，两把尺。**

   若后台技术或 manager 认为某条 `expect` 标错，**以驳回为准，我改标注不改数字**。
